# Inspiration interview

## Questions

Ask both in one round. Give a recommended option for each.

1. **More of**: what should the feed show more of?
    - Offer two or three bundles of four or five topics each, built from the user's work and the content they make.
    - Let the user combine bundles ("1 and 2") or write their own.
2. **Less of**: what should it show less of?
    - Default: leave empty.
    - Otherwise, offer a bundle of categories that are far from the user's work.
    - Ask about borderline categories (for example memes, which can still be useful as hook references) instead of guessing.

## Turning answers into topics

- Keep each topic to two or three common words: `Motion graphics`, not `cool motion design for tech launches`.
- Split compound ideas into separate topics when each half stands alone.
- If the user says "remove what doesn't fit me" without naming categories, propose the categories, state that you chose them, and include them in the confirmation.
- Do not add a topic the user did not confirm.

## Example bundles

For a creator who makes short videos about software:

| Bundle | Topics |
|---|---|
| Tech and AI | AI tools, Coding, Tech startups, Productivity, Developer tools, Open source |
| Editing craft | Video editing, Motion graphics, Viral hooks, Creator tips, Storytelling |
| Launch work | Product launch videos, Explainer animation |

Less of, for the same creator: Dance challenges, Fashion, Lifestyle vlogs, Makeup.
